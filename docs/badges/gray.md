# gray 家族

代表色：`#808080`
家族定位：围绕「三通道相等 / 接近相等」这条灰阶主轴，在**极差维度**（相等、近灰）与**明度区间维度**（暗部、中段、亮部）上各取一条，最后用一条极窄的中位残响收尾。

> 📖 本家族的徽章表（含判定条件、命中数、概率 p 与 CP）见 [../BADGES.md](../BADGES.md) 的「### gray — 灰阶」一节。CP 与稀有度由全色域概率推导（`ep = 100 / p`），请勿手写。

## 备注

- **反冗余说明（重点看护的两对）**：
  - `gray-true-monochrome`（R = G = B）与 `gray-shadow-zone`（三通道极差 ≤ 4，且最大值 ≤ 24）**不构成蕴含**：
    `#808080` 满足前者但不满足后者（最大值 128 > 24）；`(20, 20, 22)` 满足后者但不满足前者（极差为 2）。
    两者只在中、暗部的严格灰上部分重叠，任一都不是另一的子集。
    同理 `gray-frost-zone`、`gray-mid-zone` 也都同时容纳「严格灰」与「近灰」，故都不被 `gray-true-monochrome` 蕴含。
  - `gray-near-neutral`（三通道极差为正，且不超过 2）与 `gray-mid-zone`（三通道极差 ≤ 1，且三通道都落在 100–156）**不构成蕴含**：
    前者包含 `(10, 10, 12)`（越出中段亮度），后者包含 `(128, 128, 128)`（极差为 0，被前者的「> 0」排除）。
- **有意的排除项**：
  - `gray-near-neutral` 显式加 `0 <`：若写成「三通道极差 ≤ 2」，会把全部严格灰吞进来，从而成为 `gray-true-monochrome` 的超集。
  - `gray-shadow-zone` / `gray-frost-zone` 的极差阈值取 4（而非 2）：既避开 `gray-near-neutral` 的极差区间，也让暗部/亮部各自成为独立的明度维度，而非近灰维度的更细切分。
  - `gray-core-echo` 用「极差 = 3」而非「R = G = B = 128」：后者是 `gray-true-monochrome` 的子集，属第 6 节明确禁止的蕴含式重复。
- **排除掉的候选**：「R = G = B 且 R 为 2 的幂」「R = G = B 且 R < 255」「三通道相等且亮度极低/极高」——它们全部是 `gray-true-monochrome` 的真子集。
- 极差定义为三通道最大值与最小值之差（最大/最小取三通道），阈值均为闭区间，读者可直接手算。
