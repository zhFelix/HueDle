# channel 家族

代表色：`#00FF00`
家族定位：不关心是哪一种颜色，只关心三个通道之间的序关系与值域高低。

> 📖 本家族的徽章表（含判定条件、命中数、概率 p 与 CP）见 [../BADGES.md](../BADGES.md) 的「### channel — 通道」一节。CP 与稀有度由全色域概率推导（`ep = 100 / p`），请勿手写。

## 备注

- **家族内无蕴含对子**，六个条件分属四个互不包含的维度：
  1. **严格全异序**：递减序与递增序是两个不同的排列，互斥；
  2. **值域**：高值通道与低值通道以 128 为界互补，互斥；
  3. **含相等的序**：双峰突起要求恰有两个通道相等**且该相等值 > 0**，第三个通道严格更大。
     它不含全异序（递减序/递增序都要求三通道互不相等），也不被值域条件包含（例如 `(10, 10, 50)` 命中双峰
     却落在低值通道里，而 `(200, 200, 250)` 命中双峰却落在高值通道里——交叉但互不包含）；
     额外的「相等值 > 0」不是凑数尾巴，而是为切断跨家族蕴含：若允许相等对为 0，
     则 `(R, 0, 0)` 这类颜色会同时命中 pure 家族的唯赤/唯绿/唯蓝，形成 `pure-only-red ⊂ channel-twin-high`
     的子集关系（跨家族蕴含，第 6 节建议避免）。加上该限制后三组单通道纯色全部落在双峰之外。
  4. **极值错位**：精确到单一通道三元组 `(255, 0, 128)`，三个通道互不相等且非单调，
     因此不是递减序/递增序的子集；`G = 0` 使它不属于高值通道，`R = 255` 使它不属于低值通道，
     三通道互不相等使它不属于双峰突起。
- **为何不写「R > G」这种半序条件**：它会被递减序完全蕴含（递减序 ⊂ R > G），
  属于第 6 节明令禁止的蕴含对子，故本家族只用完整的三通道序，不写二通道序。
- **与 gray 家族的 R = G = B 不重叠（刻意避让）**：本家族**没有任何**「三通道全同」条件，
  六个条件全部要求至少存在一处严格不等或落在特定值域关系上；即使高/低值通道可能命中灰阶颜色
  （如 `(200,200,200)`），其判定依据是值域而非「三通道相等」，与 gray 的维度不同，不构成逐字重复。
  跨家族的部分重叠是规范允许的，仅记录不冲突。
- **极值错位为何是 anomaly**：满值 255、零值 0、半值 128 三个极端通道按 `R/G/B` 排列，
  在 2^24 色空间中只命中 1 个颜色。
- **条件的概率对称性**：高值通道与低值通道以 128 为界互补，命中集合大小相同；递减序与递增序互为通道置换，命中集合也同宽。
  分值改由命中概率推导后，这两对各自自然同档，区别不再由作者指定。
