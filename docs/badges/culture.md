# culture 家族

代表色：`#002FA7`
家族定位：认领真实存在的文化 / 商业 / 艺术「名色」——克莱因蓝、蒂芙尼蓝、马尔斯绿、普鲁士蓝、提香红、梵高星空蓝、中国传统色。本家族是规范第 5 节 check 约束 3 的**特许例外**：允许精确 hex 比较。

> 📖 本家族的徽章表（含判定条件、命中数、概率 p 与 CP）见 [../BADGES.md](../BADGES.md) 的「### culture — 文化」一节。CP 与稀有度由全色域概率推导（`ep = 100 / p`），请勿手写。

## 备注

### 反冗余（同家族内）
- 8 条全部是精确色值，且 8 个 hex 两两不同，命中集合天然互斥：任何颜色最多命中 1 条，不存在蕴含对子，也不存在子集关系。
- 8 条各自只命中 1 色，命中概率完全相同，因此 `ep = 100 / p` 导出的档位也相同；不再按名色知名度手工分级。
- 曾考虑用「梵高星空蓝 HSL 窄带（H ∈ [210,235]、S ∈ [35,75]、L ∈ [18,38]）」，实测该窄带**恒满足** `pattern-ascending`（色相 210–235 必然导致字节序 R<G<B），即构成跨家族的**真子集**关系；为避免这类蕴含，改用精确色值 `#1B3B6F`。

### 跨家族重叠说明
- 与 `pure` / `extreme` 家族：culture 用的是**精确色值**（`hex === '#002FA7'`），pure/extreme 用的是**通道归零或取极值**（`R = G = 0 且 B > 0`、`R,G,B ∈ {0,255}`），是不同维度，不构成蕴含：
  - `#002FA7`（R = 0，G = 47，B = 167）只满足「单通道为 0」，不满足纯蓝的 `R = G = 0`；`#003153`（R = 0，G = 49，B = 83）同理。
  - 8 个色值均不是 `{0,255}` 的三元极值组合，不会被 extreme 的极值条件蕴含。
  - 已刻意避开纯黑 `#000000` / 纯白 `#FFFFFF`，把极端家族的核心领地让出。
- 与 `pattern` 家族：仅存在**单个色值**的巧合重叠，不构成设计层面的蕴含（任何精确色徽章都不可避免地会落在若干通用模式里）：
  - `#002FA7` 的字节序为 `00 < 2F < A7`，同时命中 `pattern-ascending`；且 `00` 相邻相同，命中 `pattern-echo`。
  - `#1B3B6F` 的字节序为 `1B < 3B < 6F`，同时命中 `pattern-ascending`。
  - 这类重合是 `pattern` 家族通用宽条件徽章的固有覆盖面，`culture` 判定的是「是否等于某个特定名色」，与「字节是否递增」判定的维度不同。

### 阈值选择
- 「天青」`#87CEEB` 与 Pantone 年度色未纳入，避免与感知家族的亮蓝 / 高饱和条件重叠。
- 精确色值均采用公开流传的标准值，描述中直接写出 hex，读者可手算核对。
