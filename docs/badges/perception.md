# perception 家族

代表色：`#FF6600`
家族定位：玩「人类肉眼看颜色时的观感」——明暗、饱和、色相落在哪一段，全部用 `hsl` 的可判定阈值表达。

> 📖 本家族的徽章表（含判定条件、命中数、概率 p 与 CP）见 [../BADGES.md](../BADGES.md) 的「### perception — 感知」一节。CP 与稀有度由全色域概率推导（`ep = 100 / p`），请勿手写。

> 全色域枚举得到的命中率（实测约：霓虹 18.7%、青绿 9.9%、紫罗兰 7.5%、青柠 7.4%、雾面 0.78%、炽白 0.43%、虚空 0.11%、暗夜 0.043%）即为概率 p，CP 与稀有度由 `ep = 100 / p` 推导，不再由作者指定。

## 备注

- **维度正交**：8 条分别落在「暗 / 亮 / 高饱和」「低饱和中亮」「黄绿色相 / 青色相 / 紫色相」「极暗却全饱和」四组不同维度，不是同一维度的细切分。
- **无蕴含对**（逐对核验，均在 60 万随机样本上有互相只命中其一的颜色）：
  - 暗夜低语要求 `s ≤ 25`，虚空悖论要求 `s ≥ 95` —— 两者完全不相交，因此不存在「虚空悖论 ⊂ 暗夜低语」。
  - 炽白之昼（`l ≥ 90`）与雾面感（`30 ≤ l ≤ 70`）、暗夜低语（`l ≤ 12`）、虚空悖论（`l ≤ 12`）、三条色相徽章（`l ≥ 15/20`）亮度区间互斥。
  - 霓虹警报（`s ≥ 85`）与雾面感（`s ≤ 10`）、暗夜低语（`s ≤ 25`）饱和度区间互斥。
  - 三条色相徽章两两 h 区间不重叠，且都带 `l ≥ 15/20` 下限，与暗夜低语 / 虚空悖论（`l ≤ 12`）完全不相交。
- **允许的部分重叠**：霓虹警报与三条色相徽章可同时命中（如 `#C85A0A` 既高饱和又落在暖橙偏红区间），但霓虹警报含蓝紫色相、色相徽章含低饱和样本，两个方向都有只命中其一的颜色，故互不为子集。
- **跨家族检查结论（规范第 6 节补充）**：
  - `perception-daylight ⊆ channel-all-high`：必然成立（`l ≥ 90` 推出 `max+min ≥ 459`，三通道都不低于 204）。这是「明度」与「通道绝对下界」两个不同维度的必然交叉，不是条件复写；要消除它只能删掉「亮色」这一感知维度。
  - `perception-night-owl ⊆ channel-all-low`、`perception-void-paradox ⊆ channel-all-low`：同理（`l ≤ 12` 推出 `max+min ≤ 61`，三通道都不高于 61）。
  - 反方向（别家 ⊆ 本家）另有多处，如 `gray-frost-zone ⊆ daylight`、`extreme-ceiling-glow ⊆ daylight`、`gray-mid-zone ⊆ misty`、`extreme-full-span ⊆ neon-alarm`，均为宽条件包含窄条件，属正常。
  - 虚空悖论**不再**蕴含 `math-coprime-trinity`（初版曾附加「三通道均 ≥ 1」，那会强制最小通道恰为 1、从而恒有 gcd = 1；已删除该附加项）。
- **与 gray 家族的边界**：暗夜低语 / 炽白之昼 / 雾面感会命中部分 `R = G = B`（灰阶 s = 0），但也含大量非灰样本（如 `#141318`、`#F5F0EB`）；反方向 `R = G = B` 也不蕴含它们（如 `#202020` 的 l = 12.55、s = 0，三条全不命中）。双向均无蕴含。
