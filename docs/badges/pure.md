# pure 家族

代表色：`#FF0000`
家族定位：只让一个颜色通道发光——单通道独亮，或恰好一个通道归零、另外两个对称亮起。

> 📖 本家族的徽章表（含判定条件、命中数、概率 p 与 CP）见 [../BADGES.md](../BADGES.md) 的「### pure — 纯色」一节。CP 与稀有度由全色域概率推导（`ep = 100 / p`），请勿手写。

## 备注

- **家族内无蕴含对子**：本家族按「零通道个数」分成两个互斥维度。
  - 单通道族（唯赤/唯绿/唯蓝）要求**恰好两个通道为 0**，三条彼此互斥；
  - 双通道族（鹅黄双峰/青碧双峰）要求**恰好一个通道为 0**、另两个非零且相等。
  - 两组的零通道个数不同，命中集合交集为空，因此不存在「A 成立则 B 必然成立」。
  - 特别地，本家族**没有**抽象的「恰好一个通道非零」总条件，否则它会把三条单通道徽章全部蕴含；
    也没有「R = 255 且 G = B = 0」这类满值条件，否则会蕴含唯赤。
- **与 gray 家族的 R = G = B 不重叠**：本家族每条都至少有一个零通道且至少有一个非零通道
  （唯赤/唯绿/唯蓝有两个零通道，双通道族有一个零通道），而 R = G = B 中唯一满足「有零通道」的是
  `#000000`，它又被「R > 0 / G > 0 / B > 0」排除。故 pure 与 gray 的命中集合完全不交。
- **品红满值为何档位最高**：它是精确到单一通道三元组 `(255, 0, 255)` 的条件，
  在 2^24 色空间中只命中 1 个颜色，是本家族中命中概率最低的一条，`ep = 100 / p` 因此最大；这是推导结果，不是手工分级。
- **三原色为何分列三条**：唯赤/唯绿/唯蓝的条件形态完全对称、命中集合同宽，保留三条只为让玩家一眼看出「亮的是哪个通道」；
  分值由各自的命中概率推导，故三条必然同档。
