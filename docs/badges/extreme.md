# extreme 家族

代表色：`#FF0000`
家族定位：贴着 0 与 255 两条色域边界玩——三通道同时触底/触顶、单侧跨度拉满、双通道满值、以及总亮度的两个端点。

> 📖 本家族的徽章表（含判定条件、命中数、概率 p 与 CP）见 [../BADGES.md](../BADGES.md) 的「### extreme — 极端」一节。CP 与稀有度由全色域概率推导（`ep = 100 / p`），请勿手写。

## 备注

- **两条「唯一精确色」并列**：`#000000` 与 `#FFFFFF` 同属全色域唯一命中的精确色，命中数相同，
  在概率定价下档位也相同；分列两条只为名称与语义区分，不再有名额限制。
- **反冗余说明（重点看护的三对）**：
  - `extreme-absolute-black` 与 `extreme-floor-glow` **不构成蕴含**：贴地微光写作 `0 < R + G + B ≤ 15`，
    显式排除了总和为 0 的纯黑；反过来 `(0, 0, 1)` 满足贴地微光却不满足纯黑。两者命中集合**互斥**。
    同理 `extreme-absolute-white` 与 `extreme-ceiling-glow`（上界取 764，排除总和 765 的纯白）互斥。
  - `extreme-dual-max`（恰有两个 255）与 `extreme-full-span`（极差 = 255）**不构成蕴含**：
    `(255, 255, 100)` 满足前者但极差为 155；`(0, 0, 255)` 满足后者但只有一个 255。二者仅在 `(255, 255, 0)` 及其 2 个排列（共 3 色）上重叠。
  - `extreme-ceiling-glow` 与 `extreme-dual-max` **不构成蕴含**：`(250, 250, 250)` 满足前者但满值通道数为 0；
    `(255, 255, 100)` 满足后者但总和为 610 < 750。重叠仅限 `(255, 255, 250)` 附近的少量颜色。
- **有意的排除项**：
  - 用「0 < 总和」而非「总和 ≤ 15」，用「总和 ≤ 764」而非「总和 ≥ 750」：否则纯粹是给纯黑/纯白加尾巴，会直接构成蕴含。
  - 未设「三通道均 ≥ 250」这类条件：它是 `extreme-ceiling-glow` 的真子集（总和必落在 750–764），属禁止的蕴含式重复。
- **排除掉的候选**：「R = G = B 且 R ≥ 250」「接近全白」「至少一个通道为 255」（后者是 `extreme-dual-max`/`extreme-full-span`/纯白的超集，会同时吞噬多条）。
